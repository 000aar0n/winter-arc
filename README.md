# WINTER ARC — 12-week training tracker

A minimalist workout and habit calendar for **October 8–December 30, 2026**. No frameworks, build tooling, or accounts needed.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository (e.g. `winter-arc`) on GitHub.
2. Upload `index.html` and `README.md` to the root of the default branch.
3. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then select your default branch and `/ (root)`. Save.
4. Wait for Pages to give you the public link (typically `https://USERNAME.github.io/winter-arc/`).

**Privacy:** GitHub Pages sites are publicly accessible. Do not upload personal body photos or private health logs to the repository. Your completed days and notes are stored only in the browser's `localStorage` and are **not automatically synced** across phones/computers. Use the Export/Import backup buttons to transfer progress; keep backups private.

## Training guidance
Monday/Thursday: push (chest, shoulders, triceps). Tuesday/Friday: band pulling and legs. Wednesday/weekends: recovery. Start today (Thursday Oct 8) with Push, Friday Oct 9 Pull + legs; Saturday/Sunday are recovery days. Start with fewer sets if needed, work with clean form, and stop if anything hurts.

The tracker is not medical advice. For teens, support normal growth with enough food, regular meals, and sleep, not aggressive cutting or forced bulking.
